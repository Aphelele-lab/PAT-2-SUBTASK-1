# Morse Code Research

## 1. Brief Overview
Morse code is a method of encoding text characters as sequences of dots (·) and dashes (–). Each letter, number, and punctuation mark has its own unique pattern. It is used to transmit messages over telegraph lines, radio, and other communication systems.

## 2. Historical Context
Morse code was developed in the 1830s and 1840s by Samuel Morse and Alfred Vail. It was created to work with the electric telegraph, which was the first practical system for long-distance communication. Before telephones and the internet, Morse code allowed people to send messages quickly across countries and oceans, and it became especially important for maritime and military communication.

## 3. How Morse Code Works
The system uses only two elements: dots and dashes.
- A **dot (·)** is a short signal
- A **dash (–)** is a signal about 3 times longer than a dot
- The space between parts of the same letter is 1 unit
- The space between letters is 3 units
- The space between words is 7 units

Example:
`S = ···`
`O = –––`
So `SOS = ··· ––– ···` was used as a universal distress signal because it’s easy to recognize.
